# 🐛 Westworld 服务器 · Bug 追踪系统

欢迎来到 **Westworld 服务器**（西域之光）的官方 Bug 追踪仓库！  
这里是玩家提交和追踪服务器问题的一站式平台。无论你遇到的是卡服、吞物品、插件报错，还是其他任何异常，都可以在这里告诉我们。

---

## 📌 如何提交 Bug？

提交 Bug 非常简单，只需要两步：

1. **点击下方链接**，进入 Bug 提交页面：  
   👉 **[提交新 Bug](https://github.com/weijiaChen0324/WestworldServerBugTracker/issues/new/choose)**

2. **按表单提示填写**以下信息：
   - 你的游戏 ID
   - 客户端类型（Java版 / 基岩版）
   - 是否为正版账号
   - Java 版玩家请填写具体版本号（基岩版玩家可留空）
   - 问题的详细描述
   - 复现步骤
   - （可选）截图或报错日志

填写完成后点击提交，我们就能收到你的反馈了！

---

## 🔍 提交前请先搜索

在提交新 Bug 之前，建议先查看 **[已有 Issues](https://github.com/weijiaChen0324/WestworldServerBugTracker/issues)**，看看是否有人已经报告过相同的问题。  
如果找到了，你可以在那个 Issue 下补充评论，而不是重复创建新的。

---

## 🏷️ 标签说明

管理员会使用以下标签来标记和处理 Issue：

| 标签 | 含义 |
|------|------|
| `bug` | 确认是 Bug |
| `待处理` | 等待管理员处理 |
| `已确认` | 已确认问题存在 |
| `已修复` | 问题已修复，等待验证 |
| `无法复现` | 暂时无法复现，需要更多信息 |
| `重复报告` | 与已有 Issue 重复 |

---

## 📢 注意事项

- 提交 Bug 需要 **GitHub 账号**。如果你还没有，可以免费注册一个（只需几分钟）。
- 请尽量**详细描述**问题，并提供**复现步骤**——这样我们能更快定位和修复。
- 如果是**紧急问题**（如服务器宕机），建议优先在服务器群联系管理员。
